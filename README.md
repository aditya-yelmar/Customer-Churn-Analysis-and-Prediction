# Customer Churn Analysis & Prediction

## Project Overview
This project focuses on analyzing customer behavior and predicting customer churn using machine learning techniques. The objective was to identify customers at risk of leaving and provide actionable insights to improve customer retention and business performance.

## Project Workflow
1. Collected and analyzed customer datasets containing 7,000+ records.
2. Performed data cleaning, handling missing values, and feature transformation.
3. Conducted Exploratory Data Analysis (EDA) to identify customer behavior patterns and churn drivers.
4. Applied feature engineering techniques to improve model performance.
5. Built and evaluated Machine Learning models including:
   - Logistic Regression
   - Random Forest Classifier
6. Compared model performance using accuracy and classification metrics.
7. Generated business insights and recommendations to improve customer retention.

## Key Insights
- Customer tenure and contract type were major factors influencing churn.
- Customers with shorter tenure showed a higher probability of leaving.
- Service usage patterns significantly impacted retention rates.
- Predictive models successfully identified high-risk customers for targeted retention campaigns.

## Business Impact
The solution helps businesses proactively identify customers likely to churn, enabling targeted retention strategies, improved customer satisfaction, and reduced revenue loss.
